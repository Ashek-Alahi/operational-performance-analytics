# Dashboard Screenshots

The repository includes a static dashboard preview at `../dashboard/executive_dashboard.html` so the project can be reviewed without Power BI.

If you build the Power BI `.pbix` version, export these page screenshots here:

- `executive-overview.png`
- `operations-performance.png`
- `finance-profit-margin.png`
- `accounts-receivable-aging.png`

Recommended screenshot checklist:

- KPI cards are visible and formatted in JPY.
- Monthly trend charts show revenue, profit margin, occupancy, and ADR.
- AR aging visual separates Paid, 0-30, 31-60, and 60+ day buckets.
- Customer collection priority table is sorted by outstanding balance.
