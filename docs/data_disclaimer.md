# Data Disclaimer

This project uses a fully simulated dataset generated by `data/generate_data.py`.

- The dataset is not from a real hotel, resort, company, SAP system, PMS, accounting system, or ERP export.
- It is designed to resemble ERP/PMS/finance/operations exports such as bookings, invoices, accounts receivable, department expenses, labor schedules, and daily sales.
- It is suitable for portfolio demonstration, technical reproducibility, SQL practice, analytics storytelling, and interview discussion.
- It should not be presented as real operational data or evidence of a real client implementation.
- Any business findings are findings from the simulated dataset only.
